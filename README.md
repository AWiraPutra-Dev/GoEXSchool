# EskulHub — Prototype Tampilan (Frontend Only)

Versi ini **khusus untuk melihat tampilan & alur UI di browser**. Tidak ada
database, tidak ada Prisma, tidak butuh `.env`. Semua data yang muncul adalah
data contoh (mock) yang ditulis langsung di kode halaman.

Baca tutorial setup lengkap di file `TUTORIAL-SETUP.md` — ikuti persis
urutannya, versi dependency di situ sudah dikunci sama seperti yang
tertulis di `package.json` supaya hasil instalasi kamu sama persis.
